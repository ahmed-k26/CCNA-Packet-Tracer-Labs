# 🌐 CCNA 200-301 Cisco Packet Tracer Labs

Welcome to my repository for **CCNA 200-301** practical labs! This collection contains fully configured and tested network topologies using **Cisco Packet Tracer**.

---

## 📁 Repository Structure

The labs are organized into structured topics to cover key networking concepts:

### 🛣️ 01. Routing Protocols & WAN
* **EIGRP Configuration**: Basic EIGRP routing setup and verification.
* **OSPF Labs**: Single-Area, Multi-Area, and basic OSPF configurations.
* **RIPv2**: Distance-vector routing protocol configuration.
* **Leased Line (Serial)**: Point-to-point serial communication configurations.

### 🔀 02. Switching & VLANs
* **VLAN Routing**: Router-on-a-Stick and Layer 3 Switch Inter-VLAN routing.
* **HSRP**: First Hop Redundancy Protocol configuration for network high availability.
* **LAN Fundamentals**: Basic switching and LAN connectivity.

### 🛡️ 03. Network Security
* **Access Control Lists (ACLs)**: Standard and Extended numbered ACL implementation.
* **IOS Recovery**: Password recovery procedure on Cisco routers/switches.

### ☁️ 04. Network Services & Addressing
* **DHCP, NAT & PAT**: Network Address Translation and dynamic IP assignment.
* **DHCP Relay**: Relaying DHCP requests across different subnets via Leased Lines.
* **IPv6 Configuration**: IPv6 addressing and static routing setup.
* **DSL Connections**: Configuring WAN DSL connectivity.

---
